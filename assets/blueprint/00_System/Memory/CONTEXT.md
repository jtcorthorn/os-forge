# Durable memory

## Inputs
Source-linked decisions and observed outcomes.

## Work
Keep cross-domain lessons here; domain facts and decisions stay in their domain. Record question, date, rationale, source and confirmed/provisional/superseded status.

Before resuming a decision or applying a prior lesson, follow the owning map and read the linked original. Check dates, current status and later corrections. Search excerpts, chat summaries and index rank are navigation aids, not authority. Use the owner's existing search/index when available; no extra memory service is required. State the searched scope and access failures. No match in a partial corpus does not mean the record never existed.

Save the useful correction once in its existing owning record. Preserve the superseded conclusion with its correction and source rather than silently rewriting history. A lesson can inform a method change within authorization; it cannot grant new permissions.

## Outputs
New records instantiated from ../../_templates/memory/RECORD.md.

## Human boundary
Never promote an inference to a personal preference or policy without confirmation.
