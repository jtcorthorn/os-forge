# Artifact design method
## Brief
Capture medium, audience, one intended action, brand source, density and hard constraints.
When unstated, infer a reversible default and label it. Ask only when the gap changes the result.
## Produce
Read source content before layout. Use actual brand assets, never invented marks.
Choose a type hierarchy, spacing scale and restrained palette appropriate to the medium.
Keep semantic tokens in the brand-owned card. Use real values or explicitly illustrative data.
Use editable originals and a rendered deliverable. Do not replace an existing approved output without versioning.
## Verify
- Render the actual output. Inspect every page/slide or important UI state.
- Check reading order, clipping, spacing, text size, contrast and source figures.
- For interfaces check keyboard, small viewport, empty/error states and long content.
- For print check page breaks and legibility. Report rendering limitations rather than claim visual acceptance.
- Record source/asset provenance and an exact output path.
## Deliver
Save the brief, editable source, final artifact and brief review record together in the owning domain.
