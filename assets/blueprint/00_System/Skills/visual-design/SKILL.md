# Visual design method

Start from the artifact's audience, job, content, and viewing context. Inspect any supplied brand assets or prior examples before choosing a direction. Extract a small system: palette with accessible contrast, type roles, spacing scale, grid, imagery rules, and chart grammar. Tie each choice to the subject and intended use.

Create one representative sample before applying the system throughout. Inspect the sample at its real viewing size. Test hierarchy, contrast, line length, density, and whether the most important fact is visually dominant. Revise tokens once, then apply consistently.

Use licensed or user-provided fonts and imagery. Record substitutions when an asset is unavailable. Preserve semantic clarity: color cannot be the only signal in a chart; decoration must not imply unsupported data. For another brand, use its actual design contract rather than these defaults.

Deliver a compact token sheet alongside the artifact when future reuse is likely. Avoid a parallel brand registry if one already exists.
