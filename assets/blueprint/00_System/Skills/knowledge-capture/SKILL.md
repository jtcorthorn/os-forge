# Knowledge capture

Capture only information that future work is likely to need: a decision, verified fact, open question, reusable lesson, or durable artifact. Locate the owning domain and its map before writing. Check for an existing record so the operation is create, update, or close, rather than duplicate.

Record date, source, status, rationale, and links to original evidence. Keep provisional inferences marked provisional. A summary is a navigation aid; it does not replace originals. Mark superseded conclusions and retain useful prior assumptions.

Distinguish local draft from an external application write. Follow the domain's permission boundary before writing to Notion, shared repositories, or other accounts. If the authoritative home is unavailable, prepare a portable capture note with the intended destination and unresolved access state; do not create a competing canonical store.
