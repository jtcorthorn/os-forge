# Channel checks

| Channel | Best available route | What to verify | Coverage caveat |
|---|---|---|---|
| Public web | Native web search/open or approved browser | Publisher, canonical URL, publication and event dates | Search index can lag and snippets omit context |
| News | Publisher article plus primary record where possible | Event date versus publish/update date | Syndication is not independent confirmation |
| Social platforms | Platform connector or authorized browser profile | Post URL, author, timestamp, thread context | Private, deleted, or ranked posts may be missing |
| GitHub | Repository source, release notes, issue/PR | Commit or release, branch, issue state | Search hits may show stale branches |
| Video and podcast | Official transcript, captions, or authorized extraction tool | Speaker, timestamp, transcription accuracy | Generated captions can mishear names and numbers |
| RSS | Feed plus linked publisher page | Entry date and current page state | Feeds may truncate or omit corrections |

Choose channels for the question. Do not auto-use every platform. A tool's successful call proves retrieval through that tool, not exhaustive platform coverage. When a platform requires login, use only the user-authorized account/surface. Keep credentials out of commands, logs, and deliverables. External posting is outside this retrieval method.
