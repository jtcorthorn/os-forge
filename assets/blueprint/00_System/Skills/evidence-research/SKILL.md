# Evidence-grounded research

1. State the decision or question and what evidence would change the answer. Set a bounded source plan: primary record, current event channel if status is live, and independent checks where useful.
2. Retrieve the actual document, page, thread, or dataset where possible. Record source owner, date, scope, and access limitations. Search results are leads, not full evidence.
3. Separate extracted facts, calculation, interpretation, and speculation. For every consequential claim, point to the exact source passage or data field. Verify quoted text and units against the original.
4. Resolve conflicts by comparing dates, definitions, coverage, and authority. Do not silently prefer the newest page if it measures a different thing.
5. Write the answer around the decision. Add a short claim-to-source table when the output is substantive or signed by a person. Report uninspected channels and what they could change.
6. Stop when the evidence is sufficient for the stated decision; do not expand into an open-ended survey without a material reason.

Use deterministic tools for counts, arithmetic, and comparisons. A citation marker, matching file size, or model-generated summary is not verification.
