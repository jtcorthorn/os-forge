# Presentation craft

Name the audience, decision, and one sentence takeaway for the deck. Build a storyline before arranging slides. Each slide should have one point expressed in its title and evidence sufficient for that point. Choose a layout that fits the content, not a repeated template regardless of meaning.

Apply an inspected brand system or create a small visual system for the deck. Use editable text, native charts/tables when practical, readable labels, and source footnotes for consequential claims. If adapting an existing deck, preserve master/theme intent and check embedded assets.

Render every slide and inspect at presentation size. Check overflow, font substitution, contrast, crop, chart interpretation, and continuity. Validate cited numbers against their source. Retain the prior version before replacement.

Read [references/runtime.md](references/runtime.md) for optional tooling. Distinguish a generated PPTX from a visually verified deck.
