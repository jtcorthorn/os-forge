# Presentation runtime choices

Use PowerPoint or a connected Slides editor when available. `python-pptx` can generate and edit many `.pptx` elements but does not prove that a deck renders correctly. LibreOffice or a native preview can render slides to images or PDF for visual inspection; differences in fonts and animations may remain. For cloud decks, use the authorized connector and preview in the target app. Record the actual editor and renderer. This skill carries no fonts, templates, licenses, or executable dependencies.
