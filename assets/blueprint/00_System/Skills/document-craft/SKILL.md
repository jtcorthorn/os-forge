# Document craft

Define recipient, purpose, decision or action, and required format. For an existing document, inspect its structure and preserve intentional styles, comments, fields, and tracked changes. Draft the core argument before formatting.

Use real heading styles, stable tables, captions, page breaks, and accessible alt text where appropriate. Prefer a small style system over per-paragraph overrides. Keep source claims traceable in notes or a separate claim-to-source table when the document is substantive or signed.

Render or open the actual output in a capable viewer. Check pagination, widow headings, clipped tables, headers, footers, links, and special characters. A successful file save does not prove layout. Make one targeted repair pass for defects that affect use. Retain the previous version before replacement.

Tool dependencies vary by runtime. Read [references/runtime.md](references/runtime.md) for setup options; mark the result unrendered if no renderer is available. Do not claim that a bundled editor or plugin is installed.
