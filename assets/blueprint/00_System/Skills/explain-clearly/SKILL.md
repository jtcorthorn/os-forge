# Explain clearly

Extract the core claim, mechanism, stakes, and decision from the source before simplifying. Choose the audience from context: newcomer needs the mechanism, executive needs consequence and decision, cross-domain specialist needs a mapping to familiar concepts. Ask only when the audience materially changes the result.

Draft in plain language, defining each necessary term at first use. Use an analogy only when it preserves the mechanism; state where it breaks if that matters. Translate numbers with units and a relevant comparison, never a decorative comparison that distorts scale.

Check every simplification against the source. Surface places where the source itself is ambiguous or your understanding is incomplete. Keep the main explanation clean, with a brief uncertainty note where needed. A clearer sentence must not claim more than the evidence supports.
