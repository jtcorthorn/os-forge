# PDF craft

Identify whether the PDF is born-digital, scanned, fillable, or a layout reference. For extraction, compare text extraction with page images on a sample that includes tables, columns, and footnotes. OCR is an interpretation and must be checked for consequential values.

For creation, start from a structured source where possible. Embed or substitute fonts deliberately, keep links functional, and verify page size, margins, page numbers, tables, images, and accessibility needs. For merge/split operations, check page count and order against the request.

Render the final PDF and inspect pages at normal size, including the densest page and boundaries. Text extraction alone cannot prove layout. Preserve the original and version the output before replacement.

Read [references/runtime.md](references/runtime.md) for optional libraries and renderer choices. Report unavailable visual verification plainly.
