# Deploy or rebuild a role
1. Confirm authorized app, account, human owner and exact filesystem mount.
2. Copy or point the app profile to the canonical role card. Keep the OS source canonical.
3. Company agent: mount only the company package, not the whole personal OS.
4. Ask the fresh runtime to identify its sources and allowed outputs; inspect actual files read.
5. Have it save a harmless test artifact inside the authorized scope and read it back.
6. Record app/model/date, exact mounted path, installed skill version, probe result and evidence.
7. Mark installed or probed only for the state demonstrated. Mark in use after a real task output.

If the surface cannot write or read exact bytes, prepare a patch/handoff for a capable local executor.
Do not claim a source update has propagated to existing runtimes. Re-probe on the affected station.
