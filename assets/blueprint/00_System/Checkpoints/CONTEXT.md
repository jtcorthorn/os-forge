# Workstream continuity

## Inputs
User request, owning domain, actual work files and approved next actions.

## Work
Write one clear continuation record from ../../_templates/checkpoint/CHECKPOINT.md. Company checkpoints stay in company _agents/checkpoints. Resume by reading the named record and verifying referenced files.

## Outputs
Named live checkpoint, with prior version preserved. Close only when owner asks; retain history.

## Human boundary
A checkpoint preserves authorization but cannot create it. Do not resume closed work.
