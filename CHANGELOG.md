# Changelog

Only verified, reusable product changes belong here. Repository changes do not imply installation or activation in an owner's existing OS.

## 2026-10-21

- Added portable skill-subtree update checks and explicit read/application/property receipts, preserving local adapters and reporting unavailable collection as unknown. Unchanged reads are deduplicated within a named context; repository publication does not establish installed-host adoption.
- Corrected the public HTTPS fallback when a hosted machine has an installed but unauthenticated GitHub CLI, with a regression case for that observed runtime condition.

- Fixed fresh-build verification failures caused by nested workshop archives: exclude history and bytecode from deployment, preserve recipient history, and check active links without treating archived snapshots as current navigation.
- Added a self-service Spanish start: private recipient root, one useful task, a few optional sources, originals kept in place and no account connections required.
- Clarified that the six prepared roles can be used sequentially by one assistant; unused roles and optional cleanup do not block a useful first implementation.
- Added fresh-session result discovery to handover and source/status checks for retrieved lessons, with explicit limits for unavailable access and partial search coverage.

## 2026-10-12

- Added dependency-pin reconciliation guidance after an observed hosted integrity stop: preserve the hash guard, check the approved change and affected deployment references, then distinguish a verified reference repair from an actual hosted retry.

## 2026-10-11

- Clarified how small and substantial verified improvements, including fleet evolution notes, enter the existing neutral package: preserve private evidence at its source, test the portable behavior, then build a publication snapshot with a concise changelog. Unverified or owner-specific changes stay with their owner.

## 2026-10-08

- Documented verified hosted-task binding when optional run metadata is absent, with fresh controller/account checks and separate source-only, no-op and full-cycle acceptance.
- Added full destination-ancestry verification, scoped stray-folder detection and receipt reconciliation before retrying preserved duplicates.
- Clarified original-byte skill installation, host parser dependencies and suppression of temporary download credentials in terminal output.

- Added document-access routing across text, Office, PDF, image and media formats, with original-byte provenance, format-specific editing and explicit unsupported/OCR dependencies.
- Added continuous-improvement methodology and deterministic discovery for domain proposals that never entered a central ticket queue. Collection failures and missing canaries remain incomplete coverage.
- Added task-specific skill routes to the six neutral role cards and new-card template, preserving owner gates and prepared/runtime distinctions.
- Added a bounded neutral-only publication snapshot with file hashes, source/credential marker rejection and repeatable content identity. Private recipient originals and live agent/account configuration remain outside the package.
- Added publication planning that rejects corrupt snapshots, incomplete remote trees, concurrent remote edits and protected-control changes, while preserving remote-only files and avoiding duplicate commits.
- Expanded the portable method library from 17 to 19 entries. New code is covered by synthetic proposal-discovery and publication-boundary regressions in addition to the existing factory suite.
